# Stroomaansluitingen — v23 ID kopiëren tot eerste spatie

Deze versie bouwt voort op v22.

Aanpassing:
- het volledige `AANSLUITPUNT_ID` blijft zichtbaar in de interface;
- bij **Kopieer** wordt alleen het deel tot aan de eerste spatie gekopieerd;
- dit geldt voor één stroompunt én voor **Kopieer X ID's** bij een gebiedsselectie;
- tabs of meerdere spaties worden ook als scheiding behandeld.

Voorbeeld:

`AFT-075 Badengebouw pompstation`

wordt gekopieerd als:

`AFT-075`

Na deployment moet de console tonen:

`Stroomaansluitingen app v23.0.0`
